Progettazione e implementazione di una pipeline completa di Data Analysis e Machine Learning per la
classificazione di disfunzioni tiroidee su dati clinici sbilanciati. Preprocessing completo (imputazione,
scaling, encoding), riduzione della dimensionalità tramite Random Forest Feature Selection e PCA
per clustering K-Means, benchmark di classificatori supervisionati (Logistic Regression, Decision
Tree, MLP) con tecniche di bilanciamento delle classi (SMOTE, Random Over/Under Sampling).
Monitoraggio di F1-Macro e analisi dell’overfitting.
